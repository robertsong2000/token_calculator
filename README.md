# Token 价格计算器

一个纯前端的 LLM Token 费用估算工具,用于对比**不同缓存命中率**下处理指定数量 Token 的总费用。单文件实现,无需安装任何依赖,浏览器打开即用。

## 功能特性

- **模型预设**:内置多组模型单价(输入 / 缓存命中 / 输出,元每百万 tokens),点击一键填充,也可手动修改任意价格
- **场景预设**:针对不同业务场景(如 Agent 长程任务、通用对话、RAG 问答、代码补全)预置了典型的输入占比与缓存命中率组合
- **灵活的参数输入**:
  - 总 Token 数量支持「个 / 万 / 百万 / 亿」单位切换
  - 滑块调节输入 Token 占比(其余为输出)
  - 缓存命中率列表可自由增删(逗号分隔)
- **结果展示**:
  - 每个命中率下的费用明细(命中 / 未命中 / 输出的 tokens 与费用)
  - 与无缓存基准对比的节省金额与节省百分比
  - 直观的条形图费用对比
  - 综合单价(每百万 tokens 的实际均价)总结
- **实时计算**:任意参数变化立即重新计算,无需点击按钮

## 快速开始

直接用浏览器打开 `index.html` 即可,无需构建、无需服务端。

```bash
# macOS
open index.html
```

## 计算说明

费用按以下方式拆分计算(缓存命中率只作用于输入部分,输出始终按输出价格计费):

```
输入 tokens = 总 tokens × 输入占比
输出 tokens = 总 tokens × (1 − 输入占比)

命中 tokens = 输入 tokens × 缓存命中率
未命中 tokens = 输入 tokens × (1 − 缓存命中率)

总费用 = 命中 tokens / 1e6 × 缓存命中单价
       + 未命中 tokens / 1e6 × 输入单价
       + 输出 tokens / 1e6 × 输出单价
```

同时以缓存命中率 0% 作为基准,计算各命中率下的节省金额与节省比例。

## 自定义预设

预设数据以常量形式写在 `index.html` 的 `<script>` 中,直接编辑即可:

- `MODELS`:模型单价预设(元 / 百万 tokens),字段为 `name`、`input`(输入价)、`cache`(缓存命中价)、`output`(输出价)
- `PRESETS`:场景预设,字段为 `name`、`ratio`(输入占比 %)、`rates`(命中率列表 %)
